# Tomato design fidelity map

This mechanical comparison uses Tomato commit `1bba8459cb20029f8544efa96c5d62181a769bed` from `/tmp/plink-tomato-reference` and the current Plink adaptations listed in `third_party/tomato/PROVENANCE.json`. It describes source reuse and parameter correspondence; it is not a claim that the products have identical screens or behavior.

| Area | Pinned Tomato source | Plink adaptation | Exact retained or adapted parameters | Deliberate Plink difference |
| --- | --- | --- | --- | --- |
| Typography | `ui/theme/Type.kt` | `ui/theme/Type.kt` | Same Google Sans Flex file and Material typography-role mapping. Regular uses `wght=400`; rounded uses `wght=600, ROND=100`; wide display face retains `wdth=112.5, ROND=35` with Plink `wght=800`. `ss02, dlig` remain enabled across roles. | Tomato's wide face uses `wght=900`; Plink uses `800`. Plink applies the wide face to `headlineLarge` and `headlineMedium`, while display roles use the fully rounded face. |
| Shape scale | `ui/theme/Shape.kt` | `ui/theme/Shape.kt` | Plink makes the effective expressive scale explicit: extra-small `8dp`, small `16dp`, medium `24dp`, large `32dp`, extra-large `40dp`; pane maximum remains `600dp`. Grouped rows use `32dp` outer corners and `8dp` internal corners. | Tomato delegates the numeric scale to Material expressive `shapes` and uses `ListItemDefaults.segmentedShapes`; Plink implements equivalent static rounded shapes directly to avoid another dependency. |
| Theme | `ui/theme/Theme.kt` | `ui/theme/Theme.kt` | Both enter through `MaterialExpressiveTheme`. Plink supplies its adapted typography and shape set and supports light/dark schemes. | Tomato animates generated topic color schemes through MaterialKolor. Plink uses Android dynamic light/dark colors on API 31+ and fixed green fallback palettes; product state does not recolor the whole theme. |
| Floating navigation | `ui/AppScreen.kt` | `ui/FloatingNavigation.kt` | Both use an always-expanded `HorizontalFloatingToolbar`, vibrant toolbar colors, per-destination `ToggleButton`s, selected/unselected primary-container colors, selected icon `Crossfade`, expanding selected labels, `ButtonDefaults.IconSpacing`, and a `56dp` control height/minimum. | Tomato can expose labels for a wide layout and uses `motionScheme.defaultSpatialSpec()` for label expansion. Plink exposes only the selected label, uses three fixed destinations (Connection, Activity, Settings), circle shapes for all toggle states, and default Compose animation specs so system animation scaling still applies. |
| Central ring | `ui/timerScreen/TimerMainPane.kt` | `ui/ConnectionRing.kt` | The circular pane structure, animated scalar, centered animated content, `CircularProgressIndicator`, `16dp` stroke, `8dp` gap, and square aspect ratio come from Tomato's timer pane. Plink constrains the pane to `350dp`, uses `88%` available width, and sizes the ring to `90%` of that pane. | Tomato animates timer mode, color interpolation, and clock size with Material motion specs. Plink animates connection progress from `0.08` to `1.0` with `spring()` and swaps `SessionStatus` content using `AnimatedContent`; its center label is `58sp` and reports Pair, Ready, or Pair again. |
| Settings composition | `ui/settingsScreen/screens/SettingsMainScreen.kt` | `ui/PlinkAppScreen.kt` | Both use a centered expressive top app bar, a `32sp/32sp` heading, a `LazyColumn` with `2dp` grouped-row spacing, `16dp` horizontal content padding, `12dp` section separation, a `600dp` pane maximum, and segmented rows with large outer/small inner corners. | Tomato rows navigate among timer settings. Plink rows bind real continuity feature, permission, background-connection, and file-transfer state. Supporting text is allowed to wrap fully at large font scales. |
