# Plink Mac icon

`Plink.icns` is a static icon asset generated by native AppKit drawing in
`scripts/generate-macos-icon.swift` from the official Lucide `link.svg` paths at
commit `951813ce76a859d4d8b145366972cbb237147a4e` (ISC License). It uses a
neutral rounded background and blue link mark. No SVG renderer ships with Plink.
